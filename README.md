## Tutorial Instalasi

### 1. Buat repository profil
1. Masuk ke GitHub.
2. Buat repository baru dengan nama yang sama persis dengan username GitHub Anda, misalnya `Ws529`.
3. Pastikan repository bersifat publik.
4. Inisialisasi dengan file README.

### 2. Clone menggunakan Git
Buka terminal lalu jalankan:

```bash
git clone https://github.com/Ws529/Ws529.git
cd Ws529
```

### 3. Buka di Visual Studio Code
Jalankan:

```bash
code .
```

### 4. Tempatkan setiap file di folder yang benar
- Letakkan isi utama di `README.md`.
- Letakkan banner dan gambar di `assets/images/`.
- Letakkan animasi di `assets/animations/`.
- Letakkan file workflow di `.github/workflows/snake.yml`.

### 5. Unggah banner dan GIF
- Ganti gambar banner dengan mengedit `assets/images/banner.svg`.
- Ganti pratinjau animasi dengan mengedit `assets/animations/anime-coding.svg`.
- Jika ingin banner PNG di kemudian hari, ekspor desain dari Figma atau Canva lalu simpan sebagai `banner.png` di root repository.

### 6. Edit README.md
Buka `README.md` dan perbarui:
- Username GitHub Anda pada semua tautan badge.
- URL portofolio Anda.
- Alamat email Anda.
- Tautan dan deskripsi proyek.

### 7. Pratinjau Markdown di VS Code
Buka file README lalu tekan:
- Ctrl+Shift+V untuk pratinjau berdampingan.

### 8. Commit perubahan
Jalankan:

```bash
git add .
git commit -m "Buat profil GitHub yang lebih rapi"
```

### 9. Push ke GitHub
Jalankan:

```bash
git push origin main
```

### 10. Aktifkan GitHub Actions
1. Buka repository di GitHub.
2. Masuk ke tab Actions.
3. Jika diminta, aktifkan workflow.
4. Workflow snake akan berjalan otomatis setelah push pertama.

### 11. Aktifkan animasi Snake
1. Setelah workflow berhasil dijalankan, buka tab Actions.
2. Pastikan workflow selesai.
3. Gambar snake akan muncul di profil setelah branch output terbentuk.

### 12. Ubah banner nanti
Ganti isi di `assets/images/banner.svg` dengan desain baru atau ubah referensi file di `README.md`.

### 13. Ubah GIF nanti
Perbarui `assets/animations/anime-coding.svg` atau ganti dengan file lain lalu sesuaikan path gambar di README.

### 14. Kustomisasi profil di masa depan
- Perbarui tautan statistik dengan username Anda.
- Tambahkan proyek baru.
- Perbarui palet warna.
- Ganti file footer dan divider dengan tampilan yang lebih baru.
